# Ema-John Shopping App

**Project Type:** E-commerce Web Application  
**Repository Maintained By:** Mohammad Aminul Islam  
**Frontend:** React.js  
**Build Tool:** Vite  
**Availability:** Open-Source Learning Project

## Introduction

Ema-John Shopping App is a React-based e-commerce project designed to provide a simple online shopping experience. It demonstrates the development of a product-based shopping interface using React components, routing, and browser-based data storage.

## Features & Concepts

- React component-based development
- Product-oriented shopping interface
- Client-side navigation with React Router
- Shopping data persistence using LocalForage
- Product sorting and searching utilities
- Font Awesome icons
- Responsive front-end development concepts

## Technologies Used

- **React.js** – Building interactive user interfaces
- **JavaScript** – Application functionality
- **HTML5** – Web page structure
- **CSS3** – Styling and presentation
- **Vite** – Development server and build tool
- **React Router DOM** – Client-side routing
- **LocalForage** – Browser-based data storage
- **Font Awesome** – Icons

## Installation & Setup

Clone the repository:

```bash
git clone https://github.com/aminbiography/ema-john-shopping-app.git
```

Navigate to the project directory:

```bash
cd ema-john-shopping-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the application for production:

```bash
npm run build
```
